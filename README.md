### 🚀 Featured Projects

- 🗂️ **DevVault — AI-Powered Developer Knowledge Management System**  
  Building a knowledge retrieval system for long-running software projects that helps developers find work logs, implementation details, and previously documented solutions. Combines **semantic search, keyword-based retrieval, embeddings, and Reciprocal Rank Fusion (RRF)** to improve search relevance. Built with **Flutter, Python, FastAPI, and PostgreSQL**.

- ✈️ **[VoyageAI — AI-Powered Travel Planner](https://github.com/Sehlarazzak/VOYAGE_AI)**  
  A Flutter and Dart travel-planning application that uses **Google Gemini AI** to generate personalized, day-by-day travel itineraries for destinations across Pakistan. It tailors trip plans to users' destinations, budgets, travel duration, number of travelers, interests, and preferred travel styles. The project explores AI-generated itinerary recommendations, structured JSON responses, and API integration, with Firebase and travel-related APIs supporting the app's planned features.

- 💊 **[RxGuard AI — AI-Powered Medication Safety](https://github.com/Sehlarazzak/RXGUARD)**  
An AI-driven medication safety application designed to help users make more informed decisions about their medicines. The project focuses on medication verification, drug information, and improving awareness of potential medication-related risks. It includes a role-based system for patients, doctors, pharmacists, and administrators, with a PostgreSQL database for managing medication-related data. The project explores how AI and software engineering can support safer medication use through accessible information and a structured healthcare workflow.
